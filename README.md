# メール自動化・アポ管理ツール

このツールは、クライアントへの営業メールの送信（BCC一斉送信）、アポ日時のGoogleカレンダー自動登録、事前リマインドやアポ終了後の資料送付などのメール送信を自動化するためのWebアプリケーションです。

## 主な機能

- **クライアント管理**: 名前とメールアドレスの登録（単体/一括）。
- **一斉メール送信**: 選択したクライアントに対してBCCで一斉送信。
- **カレンダー連携**: アポ日時を設定し、Googleカレンダーに自動登録。アポ確定メールも同時送信。
- **スケジュール自動送信**:
  - **リマインドメール**: アポ日時の24時間前に自動送信。
  - **サンクス・資料送付メール**: アポ終了時刻に合わせて、事前設定した資料のリンクを含むお礼メールを自動送信。

## 必要な環境

- Python 3.10 以上
- Google Workspace (または通常のGoogle/Gmailアカウント)

## 🚀 初期設定: Google API 連携の手順 (必須)

このツールがあなたの代わりにメールを送ったりカレンダーに登録したりするためには、Google Cloud Consoleでの設定が必要です。以下の手順に従って `credentials.json` ファイルを取得してください。

### ステップ 1: プロジェクトの作成
1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスし、Googleアカウントでログインします。
2. 画面左上の「プロジェクトの選択」から「新しいプロジェクト」をクリックし、適当なプロジェクト名（例: `Email-Automation`）を入力して「作成」を押します。

### ステップ 2: APIの有効化
1. 左側のメニューから「APIとサービス」>「ライブラリ」を選択します。
2. 検索バーで **Gmail API** を検索し、選択して「有効にする」をクリックします。
3. 同様に **Google Calendar API** を検索し、「有効にする」をクリックします。

### ステップ 3: OAuth 同意画面の設定
1. 左側のメニューから「APIとサービス」>「OAuth 同意画面」を選択します。
2. User Type は **「外部」**(または組織内の場合は「内部」) を選択して「作成」をクリックします。
3. アプリ名（例: `My Automation Tool`）、ユーザーサポートメール、デベロッパーの連絡先情報を入力して保存します（他の項目は空欄で構いません）。
4. （外部ユーザー向けのテストモードの場合）左側のメニューから「OAuth 同意画面」を開き、「テストユーザー」の項目に、実際に使用する自分のGmailアドレスを追加しておきます。

### ステップ 4: 認証情報 (credentials.json) の取得
1. 左側のメニューから「APIとサービス」>「認証情報」を選択します。
2. 画面上部の「認証情報を作成」をクリックし、「OAuth クライアント ID」を選択します。
3. アプリケーションの種類で **「デスクトップ アプリ」** を選択し、「作成」をクリックします。
4. 作成されたクライアントIDの右側にある「JSONをダウンロード」アイコンをクリックしてダウンロードします。
5. ダウンロードしたファイルの名前を **`credentials.json`** に変更し、本ツールのフォルダ（`run.py` があるのと同じ場所）に配置します。

## 使い方・起動方法

### Windows の場合
本フォルダ内にある `start.bat` をダブルクリックして実行してください。
（※初回起動時は自動的に必要なパッケージがインストールされ、データベースがセットアップされます。）

### Mac / Linux の場合
ターミナルを開き、本フォルダに移動して以下のコマンドを実行します。
```bash
chmod +x start.sh
./start.sh
```

### ツールへのアクセス
起動すると、ターミナル上に `Running on http://127.0.0.1:5000` と表示されます。
ブラウザを開き、以下のURLにアクセスしてください。

**http://127.0.0.1:5000/**

### 初回ログイン時の設定
1. ダッシュボードの「Google連携設定」ボタンをクリックします。
2. 「Google 認証を実行する」ボタンを押すとブラウザでGoogleのログイン画面が開きます。
3. 自分のアカウントを選択し、アクセスを許可してください（警告が出た場合は「詳細設定」から安全でないページへ進むを選択してください）。
4. 連携が完了すると、自動的にツール内でメール送信やカレンダー登録ができるようになります。
